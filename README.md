# História em Jogo — hstgames

Versão 10.2: Roma, Grécia, Egito e Europa medieval. Dezoito personagens e 162 missões.
Cintos medievais com caimento integrado ao tecido: pregas, contato e volume para roupa clara e vestes coloridas dos quatro personagens.
Guarda-roupas por arraste, toque/clique e teclado. Arte rasterizada gerada por IA e rotulada como ilustração didática. Fontes e limites históricos no portal.
HTML offline entregue com todas as imagens incorporadas.
https://bragatrosco.github.io/hstgames/
